## 2. Відповідь на контрольне запитання

**Запитання:** Як працює функція `map()`? Наведіть приклад її застосування.

**Відповідь:**
Функція `map()` у Python — це вбудований інструмент, який застосовує задану функцію до кожного елемента об'єкту списку чи іншого і повертає результат.Найчастіше використовується замість for.`.

**Приклад застосування з коду лабораторної роботи:**
Ми використали `map()` разом із лямбда-функцією, щоб пройтися по масиву словників (базі відгуків) і витягти з кожного лише текст коментаря:

```python
def extract_all_comments(reviews):
    """Витягує всі коментарі з бази."""
    return list(map(lambda x: x["comment"], reviews))
